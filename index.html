Cấu Hình Kết Nối Supabase Cloud

Đồng bộ tài liệu thời gian thực giữa tất cả các máy

Hướng dẫn 3 bước khởi tạo miễn phí:

  1. Tạo tài khoản tại supabase.com và tạo một Project mới.
  2. Vào SQL Editor, dán mã bên dưới rồi nhấn Run:
-- 1. Tao bang luu metadata tai lieu
CREATE TABLE IF NOT EXISTS documents (
  id TEXT PRIMARY KEY,
  title TEXT NOT NULL,
  category TEXT,
  grade TEXT,
  author TEXT,
  description TEXT,
  tags TEXT[],
  file_url TEXT,
  file_name TEXT,
  file_size BIGINT,
  file_type TEXT,
  downloads INT DEFAULT 0,
  likes INT DEFAULT 0,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- Bat quyen doc ghi cong khai
ALTER TABLE documents ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Public Access" ON documents FOR ALL USING (true) WITH CHECK (true);

-- 2. Tao Storage Bucket ten la documents (chon Public Bucket)
INSERT INTO storage.buckets (id, name, public) VALUES ('documents', 'documents', true)
ON CONFLICT (id) DO NOTHING;
CREATE POLICY "Public Storage" ON storage.objects FOR ALL USING (bucket_id = 'documents') WITH CHECK (bucket_id = 'documents');

3. Vào Project Settings -> API, sao chép Project URL và anon public key dán vào ô bên dưới:
